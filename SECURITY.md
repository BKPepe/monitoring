# Security policy

Please report a vulnerability privately to security@bloodkings.eu, in Czech or English, and not as a public issue. Steps to reproduce and the affected URL or file help most.

In scope: this repository and what it runs - https://bloodkings.eu/status/, https://bloodkings.eu/app/, the agents (agents/), https://monitoring.bloodkings.eu and https://api.bloodkings.eu.
Out of scope: the rest of bloodkings.eu (the game portal is not part of this repository), denial of service, and scanner output without a demonstrated impact.

Machine-readable contact: https://bloodkings.eu/.well-known/security.txt
